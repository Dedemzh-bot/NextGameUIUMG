# 第二次制作复盘与规范落地

日期：2026-09-18。用户授权总结第二次制作失误、落实可复用规范并提交 GitHub。本次批准的是制作方法，不是界面制作结果。

## 已确认的问题与处理

| 第二次制作暴露的问题 | 判断 | 本次落点 |
| --- | --- | --- |
| 参考内容边界、左右贴边行为和设备安全区混为一谈；计划对错误位置仍能自洽 | 适配判断与独立校验不足 | 分别判断边界职责，宽/高变化核对真实边距与移动关系 |
| 已记录分辨率换算要求，但任务生成器未正确执行 | 已有规则执行失败 | 不新增换算规则，不发布该屏换算比例或裁切参数 |
| wrap 开启时覆盖 Size To Content，Center 分支漏下放；扩大容量又改变定位 | 文本属性交接缺口 | 换行、容量、尺寸与稳定位置共同审核，逐字段确认下放 |
| 同族资源状态对应写反，镜像/颜色停留在描述；完整帧与可见边界混用 | 资源识别和表现决策不完整 | 核对用途、状态、可见内容、真实资源身份及 native 属性 |
| 美术执行范围不覆盖部分已接受字段，整体 ready 被当成完整执行 | 阶段覆盖判断错误 | 明确已执行、实际未变、待其他阶段和不支持，保留缺口 |
| 属性一致、字体预排、Designer 画面和真实渲染混为通过证明 | 证据边界不清 | 分开报告设计正确性、属性一致性、实际几何与视觉检查 |

## 发布范围

- 通过现有分析/设计接收/构建入口和 rule-card-routing 引用正文；规划、执行与验证三个阶段都能读到对应责任。路由损坏时完整回退仍保留正文。
- 本次是规范与入口落地，不声称新增自动识别或新的跨字段语义验证器；不新增前置初筛工具。测试验证路由、回退、陈旧绑定拒绝及原有回归。
- GitHub 的便携基线从规则索引 0.16 补丁更新为 0.16.1；当前项目插件从 0.21 更新为 0.22。两者引用同一份 revision 1 正文，保留各自现有能力集合；不以同版本号掩盖不同的发布范围。
- 不随本次发布本地未发布的 art 执行器、试行坐标合同、委托验收扩展；不上传项目资产、截图、运行记录、缓存或本机路径。
- 保留旧任务临时记录和已绑定文件。当前界面仍有 35 项视觉检查待完成；属性检查通过不等于这些检查通过。具体色值、裁切边界、弹窗/标记/条目尺寸不升级为通用参数。

## 迁移

新任务从现有入口读取本规范；进行中的任务重新生成受影响规则包，检查字段覆盖及未决视觉项。修改需求值时仍走原有需求修订和审核。规范发布不重写历史批准，也不替代制作结果确认与文档门禁。
