## Problem, scope and existing responsibilities

Existing Layout 0.4 already binds the actual snapshot, accepted targets, native Slots and protected identities, builds a scoped plan and uses a dedicated executor. It does not prove generator ownership of every existing widget, complete external program-reference enumeration or the safety of replaying an interrupted run. Users need a readable comparison without adding another source of execution permission.

The new informational rule `existing-update.supplemental-review` applies only when both `version=0.4` and `capability=existing-asset-layout-update/2` are selected. Calling the diagnostic is optional. Layout 0.2 creation, Layout 0.3 property-only work, art snapshot/1, complete Requirement/View/Bundle gates, existing native lowering and the dedicated executor retain their prior meanings. No keyboard/controller, locale, state or visual parameter changes are introduced.
